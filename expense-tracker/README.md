# Expense Tracker

A polished React + Vite expense tracker for recording daily spending, searching history, and reviewing totals.

## Features

- Add, edit, and delete expenses
- Categories: Food, Transport, Shopping, Bills, Other
- Search by expense name or category
- Dashboard stats: total spent, total expenses, average expense, and highest expense
- Form validation and confirmation before delete or clear all
- Data saved in `localStorage` so expenses persist after refresh

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal, then add an expense to see the dashboard and table update.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
